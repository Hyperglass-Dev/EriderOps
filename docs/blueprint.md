# **App Name**: E-RiderOps

## Core Features:

- Ride Tracking: Start, pause, and stop ride logging with real-time speed, distance, time, and elevation tracking using GPS, IMU, and barometer sensors.
- Scooter Model Selection: Allow users to select their e-scooter model for accurate energy modeling.
- Predictive Battery Range: Estimate remaining battery range based on the selected scooter model and current ride data, displaying a low battery alert.
- Weather Data Overlay: Integrate wind and weather data from Open-Meteo / OpenWeather as overlays on the map.
- Geofence Alerts: Provide geofence alerts for rule reminders such as speed limits.
- Automatic Crash Detection: Detect crashes using IMU and GPS patterns, prompting an emergency call modal.
- AI-powered Ride Analysis Tool: Use an LLM tool to give custom suggestions based on your stats about the route and the weather you are facing

## Style Guidelines:

- Primary color: Olive Green (#556B2F) to reflect military-inspired aesthetics.
- Background color: Dark Gray (#A9A9A9) to provide a neutral and tactical backdrop.
- Accent color: Bright Orange (#FFA500) to highlight important alerts and interactive elements.
- Body font: 'Roboto', a clear and functional sans-serif font for readability.
- Headline font: 'Oswald', a bold and condensed sans-serif font for impactful headings.
- Use robust and utilitarian icons for essential functions such as start/stop, battery, and weather.
- Full-screen live dashboard layout featuring a top row with prominent speed and distance/time displays, along with a map pane and information chips.
